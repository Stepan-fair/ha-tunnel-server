# 0.3.2 — безопасность доступа и восстановления

- Сервер применяет ограничения независимо от capabilities клиента.
- MQTT только для показаний; управление через проверенную административную панель.
- Перепроверка роли HA на каждом запросе, новые лимиты API и соединений, HSTS.
- Безопасное восстановление .hatb отзывает все прежние ключи и требует новых кодов.
- Непривилегированный Server, очищенное окружение FRP/Nginx, обновлённая база и хеши зависимостей.
- Linux тесты перед публикацией, SBOM и provenance. Границы доверия — в SECURITY.

# 0.3.0 — журнал и чистая установка

Постоянный журнал с фильтрами/CSV и backupv3, совместимый с v1/v2. Отозванные подключения скрыты в архиве; восстановление того же адреса и окончательное удаление с освобождением имени. Компактная панель для телефона и ПК, естественные русские показатели. Чистый первый запуск, защищённый мастер и раздельные проверки сети. Отдельный репозиторий Server; выпуск amd64, остальные архитектуры пока не заявлены. Приёмка новой версии отражается в ACCEPTANCE.

# 0.2.0 — доступ и телеметрия

Индивидуальный пуск/пауза и календарные сроки с бессрочным доступом; автоматическая миграция старых записей. Показ и повторная выдача одноразового кода с сохранением адреса. Проверка ответа HA, RTT, скорость и накопленный трафик. MQTT Discovery: отдельное устройство и19сущностей для каждого клиента. Backupv2 сохраняет новые данные, поддерживается восстановлениеv1. Предварительный выпуск; оставшиеся проверки перечислены в ACCEPTANCE.
